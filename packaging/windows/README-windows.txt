umoria-jp (Windows版) について
================================

■ 起動方法

日本語でプレイする場合は umoria-ja.cmd をダブルクリックしてください。
Windows Terminal がインストールされていれば自動的にそちらで起動します
（インストールされていない場合は通常のコマンドプロンプトで起動します）。

英語でプレイする場合は umoria-en.cmd をダブルクリックしてください。

■ 日本語表示について（重要）

日本語（全角文字）の表示は、ターミナルの種類により以下のように
対応状況が異なります（それぞれ原因は異なりますが、いずれも
本ソフト側では回避できない既知の問題です）。

  - Windows Terminal（推奨）        : 問題なく表示されます
  - VS Codeの統合ターミナル         : 問題なく表示されます
  - 通常のコマンドプロンプト        : 文字が重なって表示が崩れます
    （タイトルバーが「コマンド プロンプト」のウィンドウ。内部で
    使用しているncursesというライブラリのWindows版に存在する
    既知の不具合が原因です）
  - MSYS2のmintty                  : 表示が崩れる場合があります

umoria-ja.cmd はこの問題を避けるため、可能であれば自動的に
Windows Terminal で起動する設計になっています。通常のコマンドプロンプト
から umoria.exe を直接起動して日本語表示が崩れる場合は、まずWindows
Terminal（Microsoft Storeから無料で入手できます）を導入し、
umoria-ja.cmd から起動し直してください。英語表示はいずれの環境でも
問題なく動作します。

■ 推奨フォント

コマンドプロンプト／Windows Terminalのフォント設定で、「MS ゴシック」
など等幅の日本語フォントを選択してください。

■ SmartScreenの警告について

umoria.exe や umoria-ja.cmd の初回実行時に、Windowsから
「Windows によって PC が保護されました」という警告が表示されることが
あります。これはこの配布物にコード署名がされていないためで、
悪意のあるプログラムというわけではありません。「詳細情報」を
クリックし、「実行」を選択することで起動できます。

■ セーブデータ・スコアについて

セーブデータ（game.sav）とスコア（scores.dat）は、umoria.exe と
同じフォルダに保存されます。新しいバージョンに差し替える際は、
これらのファイルを誤って上書きしないよう注意してください。
